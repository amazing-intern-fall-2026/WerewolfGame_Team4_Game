Tileset Contents:
- 47 total textures and assets [48x48px]
- 2 ground autotiles
- 2 building wall autotiles
- 2 roof autotiles
- 18 cabin prop and decor assets
- 3 static ground tiles + patio and wall foundations
- Corner, edge, and decor tiles for each roof variation

=== USAGE TIPS ===
RPG Maker MZ & MV:
- Place all tilesheet images into "img/tilesets" in your RPG Maker project's files.
- In the Database menu, under "Tilesets", select just below the tilesheet type you want to import (for example, to import the ground tilesheet, click under "A2(Ground):" and select "Cabin_Exterior_A2").

Other Engines/Raw Asset Use:
- Ensure that transparent pixels are maintained for best results.
- If resizing tiles, only scale UP, not down, for best quality.
